# fire-sever notes Skill

让你的 AI agent 拉取 fire-sever 发布的笔记。

**所有读取接口都要凭证，`/api/manifest` 也不例外。** 没有 token 去调本 Skill 用的这几个读取端点，都会拿到 `401 {"error":"missing_or_invalid_token"}`（注册接口 `POST /api/register` 本身是公开的，下面就用它换 token）。

## 这是什么

fire-sever 是一个个人观点的 AI 原生订阅服务：作者把投资笔记按主题组织成卡片，按可见性分免费/付费两层发布。本仓库是一个独立的 Skill，让你的 AI agent 可以**直接读取**这些笔记。

订阅者只需要做两件事：

1. 去 `<host>/register` 注册，拿到一个读令牌（48 个十六进制字符，即 24 字节）。
2. 把令牌粘给 agent，agent 用它调 `/api/manifest` 比版本号，再调 `/api/content` 拉最新内容。

agent 本身**不要求**你理解服务端内部实现。它只需要一个读令牌，和下面这三个 HTTP 端点：两个内容端点（`manifest` / `content`）加一个图片端点。

| 路径 | 用途 | 凭证 |
|------|------|------|
| `GET /api/manifest` | 当前快照的版本号、图片清单、文件列表，以及**订阅状态头**（你的等级与到期时间） | 读令牌 |
| `GET /api/content` | 当前快照的纯文本 markdown | 读令牌 |
| `GET /images/<hash>.<ext>` | 正文里引用的图片二进制 | 读令牌 |

令牌怎么送：`Authorization: Bearer <token>` 头，或 `?token=<token>` 查询串，两者都行（同时给时以头为准）。**推荐头**——查询串里的令牌会出现在请求行上，任何记录请求行的东西（反代、网关、接入层日志）都会看到它，而这个令牌就是账号；本仓库的两个示例脚本都用头。（服务端自己不记访问日志，只记错误日志；这条是通用卫生，不是本服务的实测行为。）

## 四条指令

Skill 只提供**四条指令**，端点清单也**只有上面那三个**：

| 指令 | 什么时候用 | 会发请求吗 |
|------|------------|------------|
| `setup` | 第一次用，或令牌失效后重新绑定 | 调一次 `/api/manifest` 验证令牌 |
| `fetch` | 用户说"拉一下笔记 / 今天的最新版本" | 先 `/api/manifest`，需要时再 `/api/content`（图片另算） |
| `status` | 用户问"我是什么等级 / 还剩几天" | **只**调 `/api/manifest`，不拉正文 |
| `ask` | 用户问"这个怎么用 / 怎么订阅 / 怎么续费" | **一个请求都不发** |

**失败怎么重试**：**网络不通 / 超时**（没有 HTTP 状态码那种）最多重试**一次**，重试也失败就照实报告；**有状态码的失败一次都不重试**（`401` / `404` / `503` 直接报告）。实测这条链路上失败是常态（一次九轮的会话里出现 3 次网络失败、1 次 >5 分钟挂死，成功请求耗时 0.4–52 秒都有），所以这条尺度是写死的，不留给 agent 临场发挥。

`ask` 在用户想订阅或续费时会给出一条**管理链接**（`<host>/manage?id=<id>&secret=<secret>`）——收款码是图片，进不了对话，所以扫码必须在浏览器里打开那条链接完成。管理链接是注册成功那一次给出的，让用户自己存好（它和令牌一样是凭据，丢了找不回）。

`setup` 拿到令牌后，会把令牌**存进 agent 工具自己的存储**（下次会话不必重贴），**同时提醒用户自己复制保存一份**。agent 存的那份只是**本机便利副本**：权威副本永远是服务端那一枚，所以用户可以随时改绑、收到 401 时以重新绑定为准。想让 agent 忘掉它，说一句"重新绑定"即可。

## 每次回复都带订阅状态

`GET /api/manifest` 的 `200` 响应带两个头，这就是"等级 + 剩余时间"的来源（不需要额外请求）：

| 响应头 | 说明 |
|--------|------|
| `X-Subscription-Level` | 只有 `free` / `pro`；这个头总是有 |
| `X-Subscription-Expires-At` | ISO 8601 时间戳；**有**这个头 = 有到期时间，**没有**这个头 = 免费层 |

所以 agent 的每一条回复末尾都会有一行状态：`付费层 · 剩余 29 天` / `免费层` / `订阅已过期 · 免费层`——**包括**"没有更新"那条跳过回复和失败的回复。**还没有验证过令牌时**（用户还没把 token 给 agent）写 `未知（尚未验证令牌）`：此刻没有"上一次已知的等级"可写，写 `免费层` 是在替用户猜。**请求失败**时写上一次已知的等级 + `（未能刷新）`；从未成功过则写 `未知（未能刷新）`。天数口径是 `floor((expires_at − 现在) / 24h)`，整天向下取整：刚买完的月度订阅显示 `29 天`，不是 30 天。**「已过期」看的是时间差**（`expires_at − 现在 ≤ 0`），不是取整后的天数：剩 12 小时的订阅天数是 `0`，但它仍然是付费层。

订阅中的用户还会在正文末尾看到一行服务端追加的 `> 剩余有效期：X 天`（已取消订阅则同一行再追加「（已取消，到期后将不再续费）」）；没有这行说明当前是免费层或未订阅。两者说的是同一件事，一个是响应头、一个是正文。

如果服务器报你现在是 `free`，而 agent 手上存的正文是上次以 `pro` 身份拉到的，那份正文**不会再展示**——它属于你已经看不到的那一层。

## 怎么装

把这个仓库放到 agent 能读到的位置（直接粘 SKILL.md 的内容也行），让 agent 加载 `SKILL.md`。

最简单的方式：

```bash
git clone <本仓库地址>
# 然后在你的 agent 配置里把 SKILL.md 的路径指向它
```

## 怎么用

跟 agent 说：

> 「使用 fire-sever notes skill」

agent 会问你有没有访问 token，没有的话告诉你注册地址。拿到 token 后粘回 agent，agent 会验证它、把它存进自己的存储并提醒你也留一份，然后自动拉取内容。

> 不要把 token 发给别人、贴到 issue、写进文档。`token` 就是你的账号。

## 两个示例脚本

`examples/` 里有可以直接复制粘贴的脚本，分别用 bash + curl 和 Python + requests 演示"怎么拉一次内容"。两个脚本都跑得通，假设服务在 `http://127.0.0.1:8787`（Linux / macOS 上 Python 通常是 `python3`）：

```bash
# bash 版本
bash examples/fetch-content.sh --base http://127.0.0.1:8787 --token <你的读令牌>

# python 版本（Linux / macOS 上常写作 python3）
python examples/fetch-content.py --base http://127.0.0.1:8787 --token <你的读令牌>
```

两个脚本退出码 `0` 时把 markdown 正文打到 stdout、版本号打到 stderr（不污染正文）；失败时退出 `1`，stderr 是**一行中文**：令牌不对、服务端没有快照、连不上、参数写错都走这一条（不会甩出 curl 的英文错误或 Python 的 traceback）。Python 版在参数写错时会先由 argparse 打印一行用法，再打那一行错误。两个脚本对同一种输入给出**相同**的退出码。
